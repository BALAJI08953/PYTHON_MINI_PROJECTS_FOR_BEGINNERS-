\# Python Mini Projects



A collection of small Python projects built to strengthen programming fundamentals through hands-on implementation.



This repository contains beginner-to-intermediate Python projects covering core programming concepts such as functions, conditionals, loops, data structures, file handling, object-oriented programming, randomness, encryption, and basic quantum-computing concepts.



\## Projects



\### 1. Choose Your Own Adventure



A text-based interactive adventure game where the player makes decisions that determine how the story progresses.



\*\*Concepts:\*\*



\* Conditional statements

\* Functions

\* User input

\* Control flow

\* Basic game logic



\### 2. Password Manager



A command-line password management project for storing and retrieving credentials.



\*\*Concepts:\*\*



\* File handling

\* Data structures

\* Encryption

\* Password generation

\* Input validation



> Note: This is an educational project and should not be used to store real passwords or sensitive credentials.



\### 3. Encrypted Quantum Compiler



An experimental Python project combining basic encryption concepts with quantum-computing ideas.



\*\*Concepts:\*\*



\* Python programming

\* Encryption

\* Quantum circuits

\* Qiskit

\* Data encoding

\* Quantum-computing fundamentals



\### 4. Quantum Python Quiz



A quiz game focused on Python and introductory quantum-computing concepts.



\*\*Concepts:\*\*



\* Dictionaries

\* Lists

\* Functions

\* Conditional logic

\* Score calculation

\* Randomization



\### 5. Rock Paper Scissors



A command-line implementation of the classic Rock Paper Scissors game against the computer.



\*\*Concepts:\*\*



\* Random module

\* Conditional statements

\* Loops

\* Functions

\* User input



\### 6. Slot Machine



A simple command-line slot-machine simulation.



\*\*Concepts:\*\*



\* Randomization

\* Lists

\* Loops

\* Functions

\* Game logic

\* Basic probability



\### 7. Time Challenge



A Python-based challenge involving timing and reaction accuracy.



\*\*Concepts:\*\*



\* `time` module

\* Date and time operations

\* User input

\* Arithmetic

\* Functions



\### 8. Typing Speed Test



A command-line typing challenge that measures how quickly the user can type a given sentence.



\*\*Concepts:\*\*



\* String manipulation

\* `time` module

\* User input

\* Functions

\* Basic performance measurement



\## Technologies Used
